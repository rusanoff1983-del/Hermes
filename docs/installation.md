# Установка и ограничения

## Зачем два компонента

`plugins/favorites-models/plugin.js` — независимый desktop drop-in. Он рисует ☆ и меню. `interface/native-model-selection.patch` — небольшой публичный SDK-мост к штатному механизму выбора модели в активном чате, включая новый чат без runtime session id. Без моста плагин не может выбрать модель нового чата корректно.

## Что делает install.py

1. Находит исходный Hermes и пользовательскую папку.
2. Проверяет применимость патча или точное наличие ранее установленного патча.
3. Сохраняет резервные копии затрагиваемых файлов.
4. Применяет только перечисленные изменения интерфейса.
5. По флагу `--install-deps` запускает `npm ci` в корне upstream (понадобится сеть).
6. Запускает реальные тесты bridge/model-controls, TypeScript и `npm run build`.
7. Если найдена Windows unpacked-сборка, копирует renderer-assets с проверкой SHA-256, затем index.html. Electron main/preload и native dependencies не подменяются. Старые chunks сохраняются.
8. Копирует плагин в пользовательскую папку и записывает receipt.

Установщик не закрывает окно, не отправляет сообщения, не перезапускает backend и не меняет конфиг провайдеров. При ошибке он завершает работу с ненулевым кодом и сохраняет partial receipt для отката — не сообщает, что установка успешна.

## Windows

Проверена установка Hermes с исходниками и `apps/desktop/release/win-unpacked/resources/app.asar.unpacked/dist`. Штатный Electron main этой версии предпочитает целый unpacked renderer. Другие схемы упаковки не объявляются проверенными.

Для MSIX-only установки без исходников установка моста не поддерживается: нужен исходный checkout и запуск его Desktop, а не ручная правка защищённого пакета.

## Linux/macOS

Python-код переносим; установка в исходники и запуск собранного Desktop предусмотрены. Автоматическое изменение Linux AppImage и macOS `.app` не реализовано. Эти платформы не проходили живую UI-проверку в данной среде.

## После обновлений

Плагин остаётся в пользовательской папке. Мост относится к исходникам и может конфликтовать с upstream. Не применяй патч принудительно: `python install.py --check` сначала проверяет его. Если он перестал подходить, нужна адаптация к новой версии, а не обход проверки.

## Личные данные

В GitHub нет состояния избранного, ключей, логов, переписок, auth.json и config.yaml. На новом ПК заново подключи свои провайдеры; только после этого выбирай модели в избранное.
